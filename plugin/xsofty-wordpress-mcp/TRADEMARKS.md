This trademark policy is separate from the GPL-2.0-or-later license covering the source code. Nothing here limits the rights granted by that license to use, study, copy, modify or distribute the code.

## Xsofty brand identifiers

The **Xsofty** name, Xsofty logo, **Xsofty WordPress MCP Bridge** product identity and related visual brand assets identify software and services originating from Xsofty (Private) Limited. This statement does not claim that every identifier is a registered trademark in every jurisdiction.

## Uses that do not require separate permission

You may:

- Make truthful, factual references to Xsofty or the original project.
- State that a project is based on, compatible with or derived from Xsofty WordPress MCP Bridge.
- Link to the official repository.
- Redistribute an unmodified official release using its original name, provided you identify the source accurately and do not imply a separate endorsement or partnership.
- Use the repository name and branding as reasonably necessary when creating a fork solely to prepare and submit a contribution to the official repository.

## Uses requiring written permission

Unless applicable law provides otherwise, written permission from Xsofty is required to:

- Use the Xsofty name or logo in the name, logo, domain, social account or marketing identity of another product, service or organization.
- Present a modified fork as the official Xsofty WordPress MCP Bridge.
- Use Xsofty branding in a way that suggests sponsorship, certification, partnership or endorsement.
- Register confusingly similar brand identifiers.

## Modified forks

The GPL permits you to modify and redistribute the code. If you publicly distribute a modified version that has not been approved and released by Xsofty, you should:

1. Give the modified project a distinct name.
2. Remove Xsofty logos and official-product presentation from the modified interface and marketing.
3. State accurately that it is an independent fork derived from Xsofty WordPress MCP Bridge.
4. Preserve copyright and GPL notices as required by the license.
5. Avoid any statement implying that Xsofty maintains, audits, supports or endorses the fork.

These branding expectations do not require removal of copyright, license, attribution or source-history notices.

## Contributions

Contributors are welcome to fork the repository, create branches and submit pull requests. A contribution becomes part of the official product only after it is reviewed and merged by the project owner. See the [official contribution guide](https://github.com/ihamzarizvi/xsofty-wordpress-mcp/blob/main/CONTRIBUTING.md).

For branding permissions or questions, contact Xsofty through [xsofty.com](https://xsofty.com).
